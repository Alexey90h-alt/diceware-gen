# 🎲 Diceware Password Generator

Простой и надежный генератор паролей, основанный на методе **Diceware**. Проект демонстрирует работу с криптографически стойкими числами и разделение логики данных.

---

## 🌟 Почему это лучше?
* **Безопасность:** В отличие от стандартных библиотек, этот скрипт использует модуль `secrets`, что делает пароли устойчивыми к криптоанализу.
* **Запоминаемость:** Метод Diceware создает пароли из реальных слов, которые легко запомнить человеку, но невозможно подобрать машине.
* **Чистый код:** Данные (словарь) отделены от логики генерации.

## 🛠 Технологии
* **Language:** Python 3.x
* **Security:** `secrets` module (CSPRNG)
* **Data Format:** JSON

## 🚀 Как это работает?
1. Программа имитирует бросок 5 игральных костей (например, получается `2-4-1-5-3`).
2. Этот цифровой код сопоставляется со словом в официальном словаре Diceware.
3. Операция повторяется 5-6 раз для создания длинной и безопасной фразы.
